# Exploratory Profile Quality Rubric v0.1

## PASS / ready
A candidate is ready for semantic review when evidence shows: breadth across materially different mechanisms; duplicates removed; at least one useful adjacent opportunity; business/data leverage assessed when applicable; at least one credible FRONTIER hypothesis when exploration is appropriate; every surviving recommendation has a testable experiment; and authorized scope is preserved. Evidence sources must be explicit, not implied.

Recommended scoring: breadth 15, causal diversity 15, non-redundancy 10, business/data leverage 15, frontier distance 20, experimentability 15, scope guard 10. Target >=80/100, with no hard-block dimension failed.

## FAIL / return / block
Return for repair when the set is shallow, commodity-only, repetitive, unsupported or not testable. Block when the profile changes scope without authorization, claims implementation authority, hides evidence gaps, or attempts canonical/runtime/production impact. A high numerical score cannot override a hard governance failure.
