# Systemic Root Cause Repair LF

Status: CANDIDATO / READ_ONLY  
Profile Pack ID: SYSTEMIC_ROOT_CAUSE_REPAIR_LF_V0_2

Transversal LF profile for recurrent or architecturally material failures. It distinguishes symptom, immediate cause and systemic root cause; resolves exact live execution authority; treats declared-vs-executed contradictions as blocking findings; evaluates whether the subject should exist at all; compares materially distinct repairs; falsifies the preferred option; and returns the minimum sufficient origin repair with hard guard and regression plan.

Final quality acceptance is independent: the candidate producer cannot self-certify the mini-judge or score rubric. Claude must evaluate the exact revision with evidence.

It is advisory/read-only. It cannot mutate GitHub, Supabase, runtime, production, strategy state, or assurance state as a consequence of its recommendation.
