# Systemic Root Cause Repair LF

Status: CANDIDATO / READ_ONLY  
Profile Pack ID: SYSTEMIC_ROOT_CAUSE_REPAIR_LF_V0_1

Transversal LF profile for recurrent or architecturally material failures. It distinguishes symptom, immediate cause and systemic root cause; reconstructs the causal chain; compares materially distinct repairs; falsifies the preferred option; and returns the minimum sufficient origin repair with hard guard, regression plan and residual risks.

It is advisory/read-only. It cannot mutate GitHub, Supabase, runtime, production, strategy state, or assurance state.
