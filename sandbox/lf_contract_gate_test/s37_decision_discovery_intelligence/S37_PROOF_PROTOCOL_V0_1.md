# S37 Proof Protocol v0.1

Status: CANDIDATE / FAIL-CLOSED

## Purpose

Demonstrate that S37 produces more domain-specific and materially differentiated business hypotheses than a normal baseline, without sacrificing grounding or safety.

## Required experiment

For each frozen holdout problem:

1. freeze source facts and authority refs;
2. execute baseline with the same underlying model/settings;
3. execute staged S37: Domain Intelligence -> Discovery -> Anti-Generic Judge -> Evolver -> Business Value Judge;
4. freeze raw outputs before scoring;
5. run deterministic portfolio validator;
6. run semantic review in an independent context with no expected winner;
7. compare baseline vs S37 on domain fidelity, unsupported claims, generic portability, false variety, decision specificity, causal specificity, falsifiability, learning-loop quality and compounding-moat plausibility;
8. persist hashes, model/settings, source revision and receipts.

## Mandatory controls

- Negative: generic personalization/segmentation with no LF-specific mechanism must fail.
- Negative: cosmetic variants of the same mechanism must fail false-variety review.
- Negative: invented discounts, guarantees, eligibility or uplift must fail.
- Negative: creditor/debtor role inversion must fail.
- Positive: LF marketplace history used to improve a specific decision, with a measurable experiment, may pass as a candidate.
- Uncertain: attractive moat claims whose necessary data scale is unobserved must remain UNCERTAIN.

## No-self-certification rule

The producer cannot certify its own differentiation. Self-check fields are hints for the semantic judge, never proof. Deterministic validation proves shape/source-binding only.

## Campaign completion

A single canary never proves S37. The bootstrap campaign must cover at least three unseen LF problem families and include baseline comparisons. Any material domain regression, unsupported business claim or judge inability to separate positive/negative controls blocks promotion.
