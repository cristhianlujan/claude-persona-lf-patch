## Bloqueos

- Faltan reglas ejecutables, ejemplos OK/NO y condiciones de stack calificadas; esta transcripción no sustituye la release.
- ADR-015 exige perfil por proyecto vinculado al repo y commit exactos; no se ha verificado un registro autoritativo.
- ADR-017 deja montos **por definir**; falta política de precios y presupuesto aprobado por pedido.
- PG-00_C3 exige revisión independiente, aprobación owner, PASE/Train y readback concordante repo + `transversal`.

No habilita PG-01_C4 ni PG-02.
