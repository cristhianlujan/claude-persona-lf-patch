# METHOD_PACK_REGISTRY v1

Governed transversal inventory of selectable reasoning/search/optimization methods.

The registry is data, not a second orchestration engine. Consumers select methods from typed signals and explicit preconditions. Every method declares cost, risk, evidence requirements, compatible capabilities, stop conditions, escalation, and validation.

SRCR remains a domain consumer. Its dynamic method catalog is evidence for the reusable pattern; its repair-specific modules/operators are not copied here.

Expensive optimization methods are present but not enabled by default. `EVALUATOR_OPTIMIZER` and `PROMPT_OPTIMIZATION` require a frozen benchmark/holdout and cost/uplift evidence. Registry presence never authorizes execution or admission.
