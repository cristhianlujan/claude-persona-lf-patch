# Wave 2 Selection-Method Qualification

This batch covers the ten Wave 2 decision families that require intelligence-method selection: A6, A7, A9, PG-02, PG-03, PG-04, TST-07, TST-08, TST-09 and TST-10.

The important distinction is now explicit: TDD, contract-first, vertical partitioning, property-based testing, FULL_SAFE_MIX and similar values can be **decision options**. The Champion contest is among the **selection/reasoning methods** that decide when those options apply, how they combine, and when uncertainty requires more evidence or a safe fallback.

The first reusable prior-art pool is IG00..IG06 from the governed IGQ 12x7 benchmark. IG05 (RIG+MAAD) and IG06 (TraceDev+Mnemosyne) showed material mix value, while the later selector+fallback comparison preserved 24/24 frozen discriminators with zero critical false-green and lower depth than the full-safe mix. These are prior-art candidates only: exact current source/version/currentness and fresh family-specific qualification are still required.

No method becomes Champion merely because it exists, is newer, scored highly historically, or belongs to a CURRENT capability. Promotion requires exact version identity, typed contract, adversarial validation, family benchmark and sealed holdout evidence under `INTELLIGENCE_METHOD_QUALIFICATION_PROTOCOL_V1`.

Model-based methods additionally record input/output token use. Budget is derived from the active model profile with reserves for governance, tools, output and recovery rather than filling the full context window. Mixes are benchmarked as first-class candidates only after their components are individually eligible.

The selector remains `CAPABILITY_SELECTOR@CURRENT`; selection never authorizes execution. No ZIP or full-repository payload is used. Holdout cases are selected only after candidate freeze and are bound by digest to the exact candidate versions.
