# Wave 2 Method Qualification

This batch covers the ten Wave 2 decision families that require intelligence-method selection: A6, A7, A9, PG-02, PG-03, PG-04, TST-07, TST-08, TST-09 and TST-10.

The candidate list is frozen before benchmarking. No method is a Champion merely because it exists, is newer, or belongs to a CURRENT capability. Promotion requires exact version identity, typed contract, adversarial validation, family benchmark and sealed holdout evidence under `INTELLIGENCE_METHOD_QUALIFICATION_PROTOCOL_V1`.

The benchmark compares candidates on decision quality, false-pass/false-block behavior, material omissions, contradiction handling, traceability, repeatability and efficiency. Model-based methods additionally record input/output token use; the budget is derived from the active model profile and reserves space for governance, tools, output and recovery rather than filling the full context window.

Mixes are benchmarked as first-class candidates after their component methods are individually eligible. The selector remains `CAPABILITY_SELECTOR@CURRENT`; selection does not authorize execution. No ZIP or full-repository payload is used.

Holdout cases are selected only after the candidate versions are frozen and are bound by digest to the exact candidate versions. This file and the associated JSON batch define the qualification procedure only; they do not fabricate benchmark results or promote any Champion.
