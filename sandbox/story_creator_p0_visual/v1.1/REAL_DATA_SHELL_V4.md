# P0 Human Review Shell V4 — real-data binding

The adjudication presentation consumes the fresh P0 V4 real-source rerun receipt directly and binds it to the exact admitted source bytes by SHA-256.

For the current Onboarding Paso 1 verification, the shell is generated from the final real rerun receipt and source image. Demo/synthetic fixtures are test-only and cannot substitute for a human-adjudication view.

The shell remains read-only until a fresh, valid human-review challenge is issued. It does not authenticate, post, infer, or persist a human decision.
