**LF Router pre-Gate2 continuity is mandatory across consumers:** When ACT-0001 returns `BLOCK_SCOPE_SEMANTICS_UNATTESTED` or `BLOCK_UNSTRUCTURED_MUTATION_INTENT_UNATTESTED`, resume semantic scope/target resolution through the canonical route. `lf_router_dispatch_v1` / `PROPOSE_ONLY_OPEN` can be ancillary research, NEVER a substitute for governed execution. A manually created Issue is only a proposal; it is not a run, an authority receipt or an official rule/policy. Never claim `100%`, `PASS`, `COMPLETED` or persistence without a new, scope-bound execution and real Supabase readback. If the canonical target/authority cannot be resolved, report the observed block, `NOT_EXECUTED`, `NO_CANONICAL_EFFECT` and the next governed action; do not manufacture a Security profile or approval. Shared check for **both GPT_NATIVE/ChatGPT and CLAUDE_NATIVE/Claude**: `sandbox/lf_contract_gate_test/profile_execution_runtime/lf_pre_gate2_consumer_gate_v1.py`. Claude Code runs it via its Stop hook; ChatGPT must run the same evaluation via an available code-execution tool before a governed closeout. This classifier is NOT a ChatGPT UI hook, not an authority receipt, and never certifies execution. Only `ALLOW_TRUTHFUL_BLOCK` (CLI exit `0`) requires and acknowledges an observed `blocking_code` field in a Router tool-result JSON object. Without a structured Router blocker, an honest `NOT_EXECUTED / NO_CANONICAL_EFFECT` report is `REPORT_NOT_EXECUTED_UNVERIFIED` (exit `5`), never a certified Router outcome; `BLOCK=2`, `DEFER_TO_GATE2_RECEIPT_GUARD=3`, `NOT_APPLICABLE=4` are also non-success. A candidate Gate2 must be structurally valid and, when supplied, bound to `literal_request`; this still does not attest its provenance. For profile runs, require the same-run Supabase 11/11 terminal readback after Gate2; for other operations use their own official receipts. Full consumer rule: [CLAUDE.md](CLAUDE.md#pre-gate2-continuity-gate--no-proposal-as-execution-fallback-mandatory).

**LF Router Gate-2 continuation is mandatory:** If a profile-selection context has `GATE2_DERIVED_PENDING_GOVERNED_ADMISSION` and `HANDOFF_CONTEXT_TO_SELECTED_PROFILE`, **do not call** `public.lf_router_pipeline_context_profile_admit_v2` through Supabase RO and do not stop on its expected `42501`. No direct profile call or intermediary.

**LF Router entry precedence:** When the user asks to **run a profile** to inspect/review/improve existing product definitions (for example Login B2B rules), use the existing **ACT-0001 context V2** path, starting at `lf_router_pipeline_context_begin_v2`, then Stage 1 V2, semantic profile selection and `HANDOFF_CONTEXT_TO_SELECTED_PROFILE` as defined in [Profiles LF runbook §6.9](ops/runbook-profiles-lf.md). Never invent profile selection, call it directly, bypass Gate 2, move secrets to the Router or use an old run as proof of a new one.


Agents MUST NOT create or modify workflows that read `LF_SUPABASE_DB_PASSWORD` or any DB credential. All database migration changes go through PR + `ready-to-merge` + the authorized Merge Train. Unauthorized database writes are `BLOCK_DB_WRITE_OUTSIDE_MERGE_TRAIN`.

Before naming a migration, apply **Migration naming** in [CLAUDE.md](CLAUDE.md): the Merge Train rejects migration names that are not classified in `sandbox/lf_contract_gate_test/migration_source_parity/lf_migration_source_parity_ci_context.py`.

Merge every PR to `main`, with or without migrations, only through the Train queue (`ready-to-merge`); never merge directly while a Train run is in flight. See **One merge path to `main`: the Train queue** in [CLAUDE.md](CLAUDE.md).

Every database write starts at the Router (ACT-0001) with an `ACTUALIZACION_DB_LF` execution and ends in the Merge Train; see **Router first for every database write** in [CLAUDE.md](CLAUDE.md).

The Router (ACT-0001) is the authority for database writes: resolve with `lf_router_resolve_v1` before each write and follow `ACTUALIZACION_DB_LF` through the Merge Train. Read-only database inspection through the Supabase RO connector is outside Router routing; limit it to the authorized inspection scope and do not use it to write.
