## Producer semantics

- `PRODUCES`: Curator logically produces the value.
- `PRODUCES_INITIAL_STATE`: Curator owns only the initial state, not later Validator transitions.
- `INITIALIZES_ONLY`: transport/persistence initialization; not a semantic conclusion.
- `INITIALIZES_SENTINEL_NOT_PRODUCER`: Curator writes only `PENDING`/empty/null sentinel values; Validator remains the logical producer.
- `PERSISTENCE_DERIVED`: guard/trigger/persistence layer derives the field.
- `SYSTEM_GENERATED`: sequence/default/timestamp generated by persistence.
- `NOT_PRODUCER`: Curator MUST NOT produce or adjudicate the field.
