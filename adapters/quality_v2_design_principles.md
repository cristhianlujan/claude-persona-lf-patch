# Adapter V2 Design Principles

1. Central routing, local specialization.
2. One profile/model execution; adapter rules are injected as a bounded capsule when applicable.
3. Zero adapter prompt cost when not applicable.
4. Canonical data is referenced, not copied into the adapter as stale authority.
5. Deterministic checks carry structural burden; semantic judges are reserved for meaning.
6. Invocation evidence is explicit and distinct from model-provider adapter metadata.
7. Candidate quality and live runtime proof are separate claims.
