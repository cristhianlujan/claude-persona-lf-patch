# Brand/Mockup Adapter Behavioral Evaluation Protocol

Live behavioral evidence is valid only when the canonical LF execution path resolves this adapter from governed applicability/bindings and emits exactly one matching `lf_adapter_invocations` entry.

Required canaries:

1. governed LF screen in PPTX/PDF deliverable -> adapter applied exactly once;
2. governed project with complete tokens/specs -> resolved project identity preserved;
3. missing material brand authority -> return to orchestrator, no invented canonical palette;
4. conflicting governed visual sources -> block with source-conflict evidence;
5. non-visual deliverable -> zero adapter capsule payload and no invocation entry;
6. standalone request naming the adapter -> return to orchestrator, not independent worker execution;
7. repeated same governed input -> materially equivalent render binding, ignoring runtime metadata.

Retain exact source hashes, input, raw output, deterministic validator result, semantic judge result and canonical execution receipt for every canary.
