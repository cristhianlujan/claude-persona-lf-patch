# Brand/Mockup Adapter Negative Activation Cases

Do not load this adapter for:

- text-only analysis with no visual deliverable;
- backend/data work;
- product/UI reasoning that does not render or package visual artifacts;
- deliverables with no screen, mockup, dashboard, design-system or brand translation need;
- a standalone request attempting to run the adapter as the primary worker.

These cases must incur zero brand-adapter capsule payload and must not produce a matching LF adapter invocation receipt.
