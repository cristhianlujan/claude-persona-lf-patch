# Brand/Mockup Adapter Quality V2 Semantic Judge

Return PASS only when:

1. the deliverable actually needs project/UI visual translation;
2. project/design-system authority is resolved from governed current sources;
3. generic templates/model defaults do not override project tokens or screen specs;
4. product and UI semantics remain owned by upstream profiles;
5. missing material brand authority returns to orchestrator instead of inventing a canonical style;
6. visual-source conflicts are surfaced with evidence;
7. selected frame/template is compatible with the target output and supplied screen semantics;
8. QA checks verify token provenance, project identity, frame integrity and absence of unsupported visual invention;
9. the applicable execution has exactly one LF adapter invocation identity;
10. the adapter can be applied through the compact capsule in the same profile/render execution path without an independent model call.

Any material failure is FAIL. Contract fixtures do not establish live-runtime execution evidence.
