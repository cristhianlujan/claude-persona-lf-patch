# Adapter Quality V2 Checklist

- [ ] Exact activation predicate
- [ ] Explicit non-activation cases
- [ ] Authority and precedence
- [ ] Bounded input contract
- [ ] Machine-readable output/binding
- [ ] Hard-fail states
- [ ] Deterministic validator
- [ ] Semantic judge where required
- [ ] Positive and negative/adversarial evals
- [ ] Behavioral evidence boundary
- [ ] Compact runtime capsule <= shared budget
- [ ] No extra model call
- [ ] LF adapter invocation evidence distinct from infrastructure adapters
- [ ] Applicable adapter evidenced exactly once
- [ ] Unbound execution adds zero adapter payload
- [ ] Standalone adapter execution not accepted as operational route
- [ ] Runtime/production/VALIDATED promotion remains separately governed
