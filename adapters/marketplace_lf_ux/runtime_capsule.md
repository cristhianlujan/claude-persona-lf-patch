# ADAPTER_MARKETPLACE_LF_UX — Runtime Capsule

Use only when Router/orchestrator resolves the Marketplace UX profile/task as applicable.

1. Bind the current Marketplace asset/surface, user objective, expected action and LF restrictions.
2. Preserve governed product/financial truth; do not manufacture eligibility, debt/payment meaning, conversion targets or UI authority.
3. Diagnose and prioritize UX friction using supplied/current evidence.
4. Separate current authority from `PROPOSED_NOT_CANONICAL` improvements.
5. Preserve supplied constraints and downstream dependencies.
6. Material missing authority -> `RETURN_TO_ORCHESTRATOR_MISSING_AUTHORITY`.
7. Conflicting governed sources -> `BLOCKED_SOURCE_CONFLICT`.
8. Output a bounded `marketplace_ux_binding` with refs, context, frictions, improvements, constraints, dependencies and blockers.
9. Record exactly one matching `lf_adapter_invocations` entry.
10. No standalone execution, second model call, runtime enablement or production promotion.
