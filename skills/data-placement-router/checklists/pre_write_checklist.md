# Pre-write checklist

- [ ] `project_code` identificado.
- [ ] `data_type` clasificado.
- [ ] Mapping existe en `project-data-map.yaml`.
- [ ] Esquema y tabla existen en Supabase.
- [ ] Columnas necesarias existen.
- [ ] Valores de catálogo/estado son válidos.
- [ ] Se buscó registro equivalente.
- [ ] Acción resuelta: REUSE / RELATE / UPDATE / INSERT.
- [ ] Si falta destino, resultado = `BLOCKED_NO_DESTINATION`.
- [ ] No se creó ninguna estructura nueva automáticamente.
